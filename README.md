# 自选基金助手 · 网页版

基于开源 Chrome 扩展 [x2rr/funds](https://github.com/x2rr/funds) 改造的**纯静态网页版**，新增**截图识别添加基金**功能。零后端、零密钥，可直接部署到任意静态空间。

## 功能

- 自选基金列表：估算净值 / 持有额 / 持有收益 / 持有收益率 / 涨跌幅 / 估算收益 / 更新时间（红涨绿跌，还原支付宝/养基宝观感）
- **截图识别添加**：上传 / 拖拽 / 粘贴（Ctrl+V）支付宝、养基宝等持仓截图，前端 OCR 自动识别「基金名 + 持有额」，匹配基金代码后入库，并提供人工校正
- 手动按名称/代码搜索添加
- 数据本地持久化（localStorage），刷新实时行情

## 运行

无需构建，任意静态服务器即可：

```bash
# 方式一：Python
python3 -m http.server 8777
# 浏览器打开 http://localhost:8777

# 方式二：Node
npx serve .
```

部署到 GitHub Pages / Nginx：直接把整个目录作为静态资源托管即可。

## 技术架构

| 模块 | 文件 | 说明 |
|------|------|------|
| 入口 | `index.html` | Vue3 + Tesseract.js（CDN 引入，无打包） |
| 存储 | `js/storage.js` | localStorage 封装，替代扩展的 chrome.storage |
| 数据 | `js/api.js` | 天天基金接口：实时估值/详情/搜索（fetch + JSONP 绕 CORS） |
| 匹配 | `js/fundMatch.js` | 全量基金代码表 + 中文名模糊匹配（含编辑距离），网络搜索兜底 |
| 识别 | `js/ocr.js` | Tesseract 中文 OCR + 截图逐行解析（兼容同行/¥换行两种布局） |
| 应用 | `js/app.js` | Vue3 根组件：列表渲染、增删改、OCR 校正入库 |

### 数据来源（均可浏览器直连）

- 实时估值：`fundgz.1234567.com.cn`（JSONP）
- 基金详情/净值：`fundmobapi.eastmoney.com`（带 CORS）
- 名称搜索：`fundsuggest.eastmoney.com`（JSONP）
- 全量代码表：`fund.eastmoney.com/js/fundcode_search.js`

### 字段计算

```
持有额   = 估算净值(或净值) × 份额
持有收益 = (净值 − 成本价) × 份额
持有收益率 = (净值 − 成本价) / 成本价 × 100%
估算收益 = (估算净值 − 净值) × 份额
```

## 说明

- 纯前端 OCR 对中文密集表格准确率有限，识别结果**务必经人工校正**后再导入；只提取「名称 + 持有额」两个关键字段以缩小出错面。
- 截图里通常只有「持有额」没有「份额」，故用 `份额 = 持有额 / 当前净值` 反推；如需精确，可在「编辑」中手动填写份额与成本价。
